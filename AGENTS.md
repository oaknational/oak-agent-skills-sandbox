# AGENTS.md

## What this repository is

A sandbox pnpm workspace for rehearsing the oak-agent-skills package and its workflows.
It holds no product code.

## Commands

- Install: `pnpm install`
- Format check: `pnpm format`. Fix: `pnpm format:fix`
- Lint: `pnpm lint`
- Test: `pnpm test`

## Rules

- Commit messages follow Conventional Commits.
- Never push straight to `main`. Open a pull request.
