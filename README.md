# oak-agent-skills sandbox

Oak National Academy uses this repository to rehearse the
[oak-agent-skills package and its workflows](https://github.com/oaknational/oak-agent-skills)
end to end, before other teams use them.

It isn't a product, and it may be reset at any time.

## How it's set up

It's set up like Oak's pnpm workspaces:

- Node 24.22.1 or a later Node 24
- pnpm 11
- a 7-day minimum release age in pnpm, matched by a 7-day Dependabot cooldown
